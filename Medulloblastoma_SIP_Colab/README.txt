MEDULLOBLASTOMA SIP — GOOGLE COLAB PACKAGE

Includes: MB_SIP_Pipeline.ipynb, MB_10_images (10 JPEG MRI images), requirements.txt.

GOOGLE COLAB:
1. Extract this ZIP on your computer.
2. In Google Colab: File > Upload notebook > MB_SIP_Pipeline.ipynb.
3. Run the first notebook code cell and upload the original entire Medulloblastoma_SIP_Colab.zip file.
4. Run the install and main pipeline cells.
5. Figures appear inline; processed PNGs and metrics.csv are under results/.

LOCAL JUPYTER:
1. Extract ZIP and open MB_SIP_Pipeline.ipynb in Jupyter from that folder.
2. Skip Colab upload cell. Run install and pipeline.

Educational processing only; generated foreground regions do not constitute a clinical tumour segmentation.
